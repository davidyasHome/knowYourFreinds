# מכיר את החברים שלך?

משחק חידון חברתי על קבוצת וואטסאפ: מנהל המשחק טוען ייצוא של השיחה, בינה מלאכותית מנסחת שאלות, והחברים עונים מהטלפון.

- `index.html` הוא האתר עצמו (קובץ אחד, מוגש דרך GitHub Pages).
- `src/index.html` הוא קוד המקור. בלוק `CONFIG` בראש הסקריפט מרכז את שם המשחק, הזמנים, הניקוד וספקי ה-AI.
- בנייה מחדש אחרי שינוי: `npm install && npm run build`.

השיחה ומפתח ה-API נשארים בדפדפן של מנהל המשחק ואינם נשמרים במאגר הזה.
